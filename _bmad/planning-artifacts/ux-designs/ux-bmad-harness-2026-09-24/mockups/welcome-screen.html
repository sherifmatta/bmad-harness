Welcome screen — three mockups

Shown on launch when no project path was passed on the command line. Nothing opens until you choose. All three are built from the harness's own tokens (dark only, NFR15) and the real portrait generator at its closed sizes, and borrow the VS Code welcome page's structure: a plain title block, text-link actions, a recent list, and a quiet second column.

        the team
        What it is. One column, one action. The five faces sit in a strip, dimmed the way idle cast cards already are; choosing one lifts it (the same 2px accent ring as a speaking portrait) and shows its intro below. Click the faces — this one works.
        Trade-off. Calmest and the most like "a place you open things from". The team intro is a step away, so a first-time user only learns the cast if they poke. Keyboard reach: the strip is five buttons, arrow-key friendly.

        Design notes that apply to all three

        Palette. The VS Code page is light; the harness is dark only (NFR15), so I kept its layout and left its colours behind. A light welcome would be a spec change, not a mockup choice.
        Voice. Harness strings stay lower-case mono with · separators; only things said are sans. The persona blurbs describe the role and name no next move (AD-21: state, never guidance) — so none says "start with Mary".
        Portraits. Real portraitV2 at 44, the cast-card size. The size set is closed (FR79); a bigger hero face would need that rule reopened.
        New things to build. A recent-projects list has no store today (chooseProjectDirectory() returns a path and forgets it). The command-line path (npm run dev -- <path>) should still skip this screen. ⌘O and folder drop are proposals.
