1Avatars, names, relative timesPaperclip's thread gives every message an avatar and a relative timestamp. The harness shows a persona portrait and a clock time today; relative ("4m ago") reads better in a long-running run.
2Activity lineA quiet system line for handoffs and state changes ("Handed to Amelia"). Paperclip's changelog names an activity line in the thread; the harness already has a sysline, so this is the same idea.
3Run transcript inline, collapsibleThe run card sits in the thread with its tool calls and a shimmer on the step in progress. Collapsed by default once the run ends. The harness already has run cards; the change is the step list and the end-state collapse.
4Chain-of-thought rowA one-line, collapsed "Thought for 12s" row above the answer, expandable. Paperclip renders chain-of-thought inline in the same thread.
5Interaction cardsPaperclip's thread has typed cards: confirm a request, tick checkboxes, answer questions, accept suggested tasks. Here: a question card with options (the harness's decision block, restyled) and a suggested-follow-ups card.
6Approval cardApprove and Request changes, with the requester and the goal it serves, as on Paperclip's approval requests. Maps to the review gate between build and code review.
7Per-message action barAppears on hover: copy, quote into composer, retry, open in its document window. Paperclip adds a per-message action bar in 2026.416.0.
8Composer: skills and handoffTyping / lists the skills for the current persona (Paperclip autocompletes skill names in its editor); @ hands over, as today. Files can be dropped in.
9Shortcut hintsPaperclip opens a cheatsheet on ?, with g-chords and j/k movement. Shown here as a quiet row under the composer; the hints are a proposal for the harness's own keys, not Paperclip's.
