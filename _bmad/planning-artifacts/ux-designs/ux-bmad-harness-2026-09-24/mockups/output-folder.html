Choosing the output folder

The Outputs half of the rail, in the four states the choice can leave it in, and the menu that changes it. The install (_bmad/config.toml, the resolver scripts) stays at _bmad/: only the folder the harness watches for a project's output is chosen.

The menu

bmad-harnessFileEditViewWindow
Output Folder…

Close Window⌘W
File ▸ Output Folder… opens the same chooser as change…, starting in the folder now watched. Use BMad's Output Folder forgets the project's choice and is dimmed while there is none. No accelerators. In a project window only; the Welcome and the document window have no project to ask about.
